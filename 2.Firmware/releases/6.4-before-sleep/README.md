# 魔杖固件 6.4 早期构建归档

本页保留 42607-P 自动休眠修复之前的镜像和测试记录。日常使用见 [6.4 稳定版](../6.4/)。

适用于 ESP32-S3-FH4R2 魔杖。同一镜像在启动时识别 ICM-42670-P 或 ICM-42607-P，灯珠数量可在魔杖网页设为 35～45 颗，默认 39 颗。

## 镜像

| 文件 | 用法 |
| --- | --- |
| [MugglesWand-6.4-app.bin](MugglesWand-6.4-app.bin) | 已有魔杖连接热点后，在「设备 → 系统升级」上传应用镜像 |
| [MugglesWand-6.4-factory.bin](MugglesWand-6.4-factory.bin) | 空白魔杖从 `0x0` 首次烧录，包含 DIO 80 MHz 引导程序、分区表和应用。用于已有设备会覆盖配置区 |

应用升级会继续使用设备原有的引导程序和分区表。需要更换引导程序的设备使用首刷流程。 [SHA-256 校验值](SHA256SUMS.txt)

ESP32-C3 红外配件使用原有镜像，电脑手势训练工具可继续通过 `.wandmodel` 更新模型。 [C3 烧录说明](../../IRLearner-C3/README.md) · [训练工具](../../../3.Software/4.GestureTrainer/README.md)

## 6.4 功能

- 42670-P 使用 FIFO 采样并支持动作唤醒。42607-P 使用轮询采样，当前保持唤醒，可按键或网页关机。设备页显示 IMU 型号。
- 内置 a、e、n、o、p、s、8、∞ 手势，首次使用时可在「手势与灯效」绑定功能。升级前上传的独立模型仍优先加载。旧内置模型的绑定按模型保存，切换到字母模型后可配置该模型的绑定。
- 保留照明、灯效、空中光绘、蓝牙鼠标与音量、Home Assistant、ESP-NOW 红外、独立模型更新和 OTA。采集页新增实时动作曲线。

## 验收状态

WSL 中通过 ESP32-S3 和 ESP32-C3 编译、71 项回归测试及两套 Chromium 固件网页测试。回归覆盖 IMU 模式切换和采样恢复、灯珠设置、模型存储与上传、灯效、蓝牙模式逻辑、Home Assistant、红外控制和 OTA。另在模拟 I²C 总线上运行实际驱动验证了两个设备 ID，以及 42607-P 的寄存器设置、数据换算和短读恢复。

用隔离的测试数据完成了实际训练、INT8 推理和 `.wandmodel` 模拟上传。新旧 C3 应用镜像的 SHA-256 相同。

ICM-42607-P 实机已从 `6.3-rc2` 通过 OTA 升级到 `6.4`。升级保留了原模型和手势绑定。灯珠数量由 39 临时改为 40，确认重启后保留，再恢复为 39。动作数据可通过 TCP 读取，光绘、鼠标和音量模式均可进入并返回识别。连续完成 15 轮采集与识别切换、约 120 秒持续采样，期间未触发 IMU 恢复。

装壳后测挥杖识别。完整实物验收还包括两种主板的冷启动、断电保存，42670-P 的 OTA 和休眠唤醒，42607-P 的关机，以及光绘显示、蓝牙 HID、红外和 Home Assistant 的实际输出。
