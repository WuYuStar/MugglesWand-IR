# 魔杖固件 6.4 稳定版

适用于 ESP32-S3-FH4R2 魔杖。同一镜像自动识别 ICM-42670-P 和 ICM-42607-P，两种 IMU 均支持静置休眠和动作唤醒。灯珠数量可在网页设置为 35～45 颗，默认 39 颗。

| 文件 | 用途 |

| [MugglesWand-6.4-app.bin](MugglesWand-6.4-app.bin) | 已有魔杖通过网页「设备 → 系统升级」更新 |
| [MugglesWand-6.4-factory.bin](MugglesWand-6.4-factory.bin) | 空白主板从 `0x0` 首次烧录。写到已有设备会覆盖配置区 |

## 休眠与唤醒

在手势识别模式下静置约一分钟后，魔杖会自动休眠。控制网页连接和系统升级会暂停自动休眠。拿起魔杖或短按底部按键可唤醒。

## 验收记录

ICM-42607-P 实机验收使用内部版本号 `6.4.1`。实测静置约 63 秒后自动休眠，抬起后的唤醒来源为 `motion`，连续六轴采样和手势识别恢复就绪。稳定版沿用这份构建的功能和配置，将固件显示版本定为 `6.4` 后重新生成镜像。已装实机验收构建的魔杖可以继续使用。

6.4 稳定版重新编译后通过 71 项软件回归测试，两个镜像均通过校验。
