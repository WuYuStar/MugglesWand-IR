# 魔杖红外配件

## 使用

给魔杖和 ESP32-C3 红外配件供电，连接魔杖的 Wi-Fi 并打开魔杖页面。在「配置 → 红外配件」中搜索 C3，点击「连接」。魔杖会记住这块 C3，重新开机后自动恢复连接。点击「添加信号」后，在 60 秒内对准接收头短按遥控器；学习成功后信号自动保存在 C3，出现在「已学信号」中，断电后保留。已有信号可以重放、改名、重新学习或删除。

「发送指令 → 红外配件」可直接选择已学信号并重放；「配置 → 手势与灯效」可将红外信号分配给手势。原来的「外部开关」入口和动作已移除，旧手势绑定中的开关动作会清空，需重新选择红外信号并保存。

魔杖和 C3 的 ESP-NOW 通信使用信道 1。若魔杖同时连接 Home Assistant 所用的 Wi-Fi，且该网络不在信道 1，页面会显示信道冲突，红外配件不能连接。C3 使用 GPIO7 接收、GPIO20 发射；接线和发射模块触发方式应与已验证的实物保持一致。

## 固件

- `wand-esp32s3-app.bin`：魔杖应用固件；可在魔杖的「设备 → 系统升级」上传。
- `ir-esp32c3-app.bin`：C3 应用镜像，适用于现有分区的增量更新。首次烧录新 C3 时，还需引导程序和分区表；使用 `2.Firmware/IRLearner-C3` 的 PlatformIO 上传命令可完整烧录。

固件均在 WSL 中编译。页面按需添加信号，不预设空白项；C3 当前存储格式最多支持 32 个信号，存满后需删除旧信号。每个信号的原始时序最多 4096 项，重放默认采用 38 kHz 载波。普通红外接收头无法测出原始载波；空调长帧和滚动码设备未保证可重放。

## 验证

魔杖与 C3 的新版固件编译通过，页面的浏览器交互检查通过，包含第 10 个信号的添加。C3 和魔杖的按需添加版均已写入并通过校验，魔杖正常启动，串口返回版本、电量等信息。最新的两处说明文字精简已编译、通过页面检查，并已写入魔杖且通过数据校验。C3 旧版曾完成断电存储检查及已学 NEC 信号的光路自检。新版页面的实机访问、两块板同时通电后的 ESP-NOW 连接和真实挥杖触发尚待实测。
